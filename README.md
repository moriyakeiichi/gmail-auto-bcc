# Gmail Auto BCC

Gmail でメール作成ウィンドウを開いた瞬間に、送信元アドレスごとに設定した BCC アドレス（最大 5 件）を自動入力する Chrome 拡張機能です。

## できること

- 送信元アドレスごとに別々の BCC を設定できる
  - 送信元 = 作成ウィンドウの「送信元」に表示されるアドレス。Gmail アカウント本体でも、Google Workspace などのエイリアス（別ドメインのアドレス）でも同じ扱い
  - 送信元に設定がなければ何もしない（別のアドレスの設定が流用されることはない）
- 作成ウィンドウを開いた後に「送信元」を切り替えると、入れた BCC を外して新しい送信元の BCC を入れ直す
- 1 送信元につき最大 5 件の BCC
- 新規作成と返信に適用（転送は初期設定では対象外。設定画面で変更可能）
- 作成ウィンドウを開いた瞬間に入力されるので、送信前に目で確認できる
- 下書きを開き直しても二重に追加されない
  - BCC 欄にすでに入っているアドレスは追加しない
  - 同じ作成ウィンドウは 1 回しか処理しない
  - 一度処理した下書きは記録しておき、開き直しても処理しない

## インストール（自分の Chrome で使う）

1. Chrome のアドレスバーに `chrome://extensions` と入力して開く
2. 右上の「デベロッパー モード」をオンにする
3. 「パッケージ化されていない拡張機能を読み込む」をクリックし、このフォルダ（`manifest.json` があるフォルダ）を選ぶ
4. 一覧に「Gmail Auto BCC」が表示されれば完了

## 設定

1. Gmail を一度開き、メールを 1 通作成してみる（ログイン中のアカウントと、送信元で使ったアドレスが検出されます）
2. 拡張機能のアイコン（パズルのピース → Gmail Auto BCC）をクリックすると設定画面が開く
   - または `chrome://extensions` の「Gmail Auto BCC」→「詳細」→「拡張機能のオプション」
3. 「Gmail で検出された送信元アドレス」からアドレスをクリックするか、「＋ 送信元を追加」でアドレスを入力
4. BCC 1〜5 にアドレスを入れて「保存」
5. Gmail のタブを再読み込みする

送信元欄に `*` を入れると、個別に設定していないすべての送信元に適用されます。

## 動作確認のしかた

1. Gmail で「作成」をクリックする
2. 作成ウィンドウの BCC 欄に設定したアドレスが入っていることを確認する
3. そのまま閉じて下書きを開き直し、BCC が増えていないことを確認する
4. 受信メールに「返信」して、BCC が入ることを確認する
5. 「転送」して、BCC が入らないことを確認する

## うまく動かないとき

Gmail のタブで `F12`（Mac は `option + command + I`）を押して「Console」タブを開くと、`[Gmail Auto BCC]` で始まるログが出ます。

| ログ | 意味 |
|---|---|
| 起動しました | 拡張機能が読み込まれている |
| 送信元 xxx の設定がないため何もしません | その送信元アドレスが設定画面に登録されていない。xxx をそのまま登録する |
| 送信元 xxx → 設定「yyy」を使います | どの設定が使われたか |
| 送信元が xxx から yyy に変わりました | 送信元の切り替えに追従して BCC を入れ替えた |
| 種別「forward」は対象外のため何もしません | 転送なので意図どおりスキップ |
| BCC は入力済みのため追加しません | 二重追加の防止が働いた |
| BCC 欄が見つかりませんでした | Gmail の画面構成が変わった可能性。修正が必要 |

ログが何も出ない場合は、`chrome://extensions` で拡張機能が有効か、Gmail のタブを再読み込みしたかを確認してください。

## 動作確認済みの内容（2026年10月21日、実際の Gmail で確認）

- 新規作成: BCC 欄が自動で開き、設定した 2 件がチップとして入る。フォーカスは宛先欄に戻る
- インライン返信: 宛先が折りたたまれたままでも BCC が入り、ヘッダーに「Bcc 2 人」と表示される。フォーカスは本文に戻る
- BCC 入りの下書きを開き直し: 追加されない（ログ「BCC は入力済みのため追加しません」）
- 転送: 対象外としてスキップ（件名の「Fwd:」と本文の「転送メッセージ」で判定）

## 制限事項

- Gmail は公式の拡張 API を公開していないため、画面の HTML 構造を読み取って動いています。Gmail 側の仕様変更で動かなくなる可能性があります。
- 返信の作成ウィンドウを開いてから「転送」に切り替えた場合、切り替え前に入力された BCC はそのまま残ります。
- インライン返信では宛先欄が折りたたまれているため、BCC は「Bcc 2 人」のような件数表示になります。クリックすると内容を確認できます。
- 「送信元」を切り替えたときに外すのは、この拡張機能が入れた BCC だけです。手で入れた BCC はそのまま残ります。
- 設定は Chrome の同期ストレージに保存されるため、同じ Google アカウントで Chrome にログインしている別の PC にも引き継がれます。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `manifest.json` | 拡張機能の定義（Manifest V3） |
| `content.js` | Gmail の画面で作成ウィンドウを監視し、BCC を入力する |
| `options.html` / `options.js` | 設定画面 |
| `background.js` | ツールバーのアイコンをクリックしたときに設定画面を開く |
